# 验证边界


## 自动检查

- `npm run check`：构建、Node 测试、文档链接。
- `npm run test:ui`：浏览器配置页交互与窄屏布局。
- `npm pack --dry-run`：打包内容检查。

测试覆盖：嵌套工具启用、保留 persona/注释/JS 标签、缺失工具追加、禁用分组、动态条件、幂等、版本冲突、只读预设、外部修改保护、精确还原、提示词开关持久化、安装失败和凭据输出不泄漏、并发操作拒绝。

浏览器测试覆盖：状态分离、显式预设选择、工具启用、提示词持久化、只读预设、冲突、连接失败、未知登录状态及移动布局。

真实 Host 验证和模型调用结果必须单独记录；模拟安装命令测试不能代表真实包安装，工具可见性不能代表 Codex/Claude 模型调用通过。
