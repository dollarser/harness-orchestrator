- 开发类型：DSH `0.1.5-rc.1`，Cordis `4.0.2`；TypeScript strict，skipLibCheck 跳过上游声明内部检查。

## 自动检查

本地 `npm run check` 通过：31 项 Node 测试、构建和文档链接检查；`npm run test:ui` 的 12 项 Chromium 页面交互测试通过。

`npm pack` 与首次安装 overlay 生成检查通过；构建先清理 dist，避免打包已删除的固定流程模块。

运行保障与集成覆盖：

- 单个 Agent 自主执行，无计划/审查 JSON 或强制验证端口；无检查任务可返回。
- Agent 自述阻塞时原样保存报告，FINISHED 不伪装为验收通过。
- 启动失败、截断/空响应、取消前后、超时、观察者异常、清理失败。
- 实际 Cordis 容器注册命令和设置，以假 provider 在真实 Git 仓库执行；配置变更只影响下次任务，卸载取消并等待清理释放锁。
- 普通目录可以运行，并在任务中初始化 Git；无首次提交和仓库子目录快照、同仓库锁共用、外部后端不收到 DSH 专用参数。
- 原有 staged/untracked 工作保留；临时 index 快照、符号链接互斥、仓库外产物、原子文件与进程取消。
- 拒绝已删除的流程字段，无命令也可启用；未知配置拒绝、模型/超时校验、原生 revision 与恢复默认值。
- 页面保存、刷新、放弃、恢复、冲突、错误、只读状态和窄屏深色布局；模型目录、联动、未知值、部分失败、重试及移除旧流程字段。

这些测试没有证明真实模型的自主决策质量。远端 CI 状态以对应提交的 Actions 记录为准。
