# Smart Dev 配置页

路径：**Settings → Smart Dev**。页面嵌入 DSH 原生设置插槽，配置由 DSH settings 服务持久化，不需要单独运行前端。

## 配置内容

- **启用 Smart Dev**：首次安装默认关闭，可以先保存不完整配置；启用时必须选定 backend 和模型。
- **执行 Backend**：默认 spawn，需要支持指定模型。
- **模型 Provider / 模型**：联动下拉框，读取原生 `session.modelCatalog()`；切换 Provider 后重新选择模型。新增模型后可刷新列表。
- **工具范围（可选）**：留空继承 DSH 可用工具与权限；填写时每行一个精确工具名，额外收窄范围。
- **任务超时**：默认 1800000 毫秒（30 分钟）；超时取消本次执行并保留记录。
- **产物与锁目录**：只读部署项，必须位于目标仓库外。

模型目录加载失败可重试；空目录引导到 DSH 的模型设置；个别 Provider 失败不影响其他正常选项。目录外的旧配置保留并提示，绝不自动改成另一个模型。目录列出某个模型不代表实际调用能力已验证。

凭据继续由 DSH 管理，此页面不存储 API Key。

## Agent 自主执行

不再提供规划 Provider、审查 Provider、强模型调用上限、修复轮次或验证命令字段。

Agent 根据任务和项目自行选择检查：文档小改动可以说明无需运行构建；逻辑修改可以运行针对性测试；遇到问题可修复并重新检查，必要时使用宿主允许的工具追加审查。插件不强制顺序或检查次数。

结果报告说明实际改动、检查结果、未完成事项和不确定性。插件的 FINISHED 仅表示 Agent 正常返回。

## 保存

- 保存使用原生 revision 防止其他页面的改动被覆盖；成功须得到宿主镜像确认。
- 有并发更新时保留草稿，载入最新配置后再编辑。
- 保存失败、只读连接、加载失败均不会伪装为成功。
- 放弃修改恢复当前宿主值；恢复部署默认值移除当前页面字段的用户覆盖。
- 保存用于下次任务；运行中的任务持有独立配置快照。
- 当前配置按宿主共享，跨项目不再要求维护固定验证命令。

不提供旧流程配置兼容，已有配置中的废弃字段需删除。详见 [架构](architecture.md)。
