# 配置页

Smart Dev 页面提供：

- Agent 预设选择；内置预设提供“创建协作版并启用”按钮。
- Codex / Claude Code 安装、Profile 配置、当前宿主注册三个状态。
- 所选预设的工具启用状态及运行实例实际可见工具。
- 安装并启用、单独启用/禁用、登录检测按钮。
- 独立分工指引开关、内容编辑与恢复默认。
- 原有工具配置的精确还原。

页面请求经过 DSH 的 `connection.rpc`，沿用宿主认证，使用 Connection 的精确 Fetch 路由 `/api/smart-dev/manage`，保留原生 RPC 请求和响应格式。不新开端口，不把 shell 命令、包名、文件路径的任意输入暴露给浏览器。

操作成功后从 Host 重新读取状态；保存失败保留原状态并展示原因。预设修订不匹配会拒绝写入。安装操作显示处理中，避免重复提交。刷新不执行模型调用。
