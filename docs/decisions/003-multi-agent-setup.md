# ADR 003：Smart Dev 改为多 Agent 接入助手

状态：接受，0.6.0 实施。取代 ADR 001/002 中独立任务执行入口。

## 原因

用户希望主 DSH Agent 自主决定规划、执行、检查、修复与审查。DSH 原生工具已经支持委派 Codex 和 Claude Code。保留 `/smart-dev` 的独立执行层重复了 Host 职责，也容易误导用户以为选择 Backend 就代表多 Agent 分工。

## 决定

移除独立任务执行及旧配置。提供原生后端安装与注册、指定预设工具启用、登录状态检测、实际工具可见性展示和非强制提示词片段。

提示词使用运行时独立 section，避免改写 persona。工具启用是持久预设修改，有备份与还原。安装和启用仅响应明确的页面操作，不在启动时静默执行。

## 后果

普通对话是唯一任务入口。插件卸载后，原生工具仍可使用。真实模型调用与任务质量不属于“安装成功”的证据。需要重启时明确报告，不为了无感体验强制中断已有会话。
